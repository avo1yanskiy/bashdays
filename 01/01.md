Если всё получилось, ты молодец
Скинь мне скриншоты со своими результатами
Погугли какие параметры для конфига существуют
Добавь в конфиг путь до своего ssh ключа
Добавь в конфиг путь к файлу логов
Если тебе нужно проверить, какие параметры активны, используй команду:

```
ansible-config dump
```

Полный ansible-config dump выводит простыню всех параметров. Для домашки удобнее использовать ansible-config dump --only-changed, он покажет только отличия от значений по умолчанию. Путь к логам должен быть доступен на запись обычному пользователю, иначе лог молча не появится или Ansible выдаст предупреждение.

Что должно быть на скриншотах

1. Вывод python3 --version и ansible --version
2. Структура каталога infra со всеми папками и файлами
3. Строка config file из вывода ansible --version, в ней должен быть путь к твоему infra/ansible.cfg
4. Вывод ansible-config dump --only-changed с настройками SSH-ключа и логирования
5. Сам файл лога после запуска ansible localhost -m ansible.builtin.ping -c local
Покажи путь к SSH-ключу, но не содержимое закрытого ключа. Файл лога тоже не добавляй в гит: в нём могут оказаться адреса серверов, имена пользователей и чувствительные значения из вывода задач.
