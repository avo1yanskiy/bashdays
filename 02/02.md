# Домашнее задание

Закрепи работу с inventory на своей лаборатории.

Создай отдельные файлы inventory/production.ini и inventory/stage.ini.
Добавь в каждый inventory соответствующий сервер, понятное имя хоста, группу web, ansible_host и ansible_user.
Проверь оба файла командами ansible-inventory --list и ansible-inventory --graph.
Убедись, что production и stage не смешиваются: при проверке каждого inventory должен отображаться только его сервер.
Запусти ansible.builtin.ping для группы web отдельно в стейдже и продакшене, получи pong от обоих серверов.
Если используешь нестандартный SSH-порт или отдельный ключ, добавь ansible_port или ansible_private_key_file и ещё раз проверь подключение.
Отправь через чат содержимое двух inventory-файлов без приватных ключей и скриншоты или текстовый вывод обеих проверок.

Что прислать на проверку

1. Содержимое inventory/production.ini и inventory/stage.ini.
2. Вывод ansible-inventory --graph для каждого файла.
3. Вывод ansible-inventory --host <имя_хоста> для каждого сервера.
4. Два успешных запуска ansible.builtin.ping с ответом pong.
