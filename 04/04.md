# Домашнее задание


1. Создай новую роль hostname
2. Напиши задачу, которая меняет hostname на серверах через модуль ansible.builtin.hostname
3. Подключи роль к стейджу и продакшену для групп web и db
4. Перед запуском проверь синтаксис плейбуков и список выбранных хостов
5. Запусти плейбуки и убедись, что hostname действительно поменялся
6. Запусти плейбуки повторно и добейся changed=0


 ## что сделать: 
1. Структуру роли hostname
2. Содержимое roles/hostname/tasks/main.yml
3. Содержимое production.yml и stage.yml
4. Вывод --syntax-check и --list-hosts
5. Первый запуск с изменениями и повторный запуск с changed=0
6. Вывод hostnamectl --static по всем серверам
